設計目標

橡實鐘是一個工作用番茄鐘。視覺概念從「專注時種樹」延伸為橡樹生命週期：小苗萌發、長出真葉、橡樹成形、開花，最後結成橡實。整體圖像維持原創，不複製 Forest 的商標、圖像或 App 版面。

0%-28%

小苗萌發

從橡實旁出現根、莖與子葉，讓使用者看到專注開始時的「種下」感。

16%-40%

長出真葉

加入裂片狀年輕橡樹葉，避免看起來像一般圓葉植物。

34%-66%

橡樹成形

樹幹、枝條與厚實樹冠逐步出現，讓專注進度變成可視化生長。

62%-80%

開花

下垂的雄花序 catkins 與小型雌花出現，銜接從開花到結果的植物流程。

84%-100%

結果

橢圓橡實、杯狀帽 cupule 與短柄逐漸顯示，作為一輪專注完成的收束。

RAG 參考流程

製作前先搜尋公開圖片與說明，萃取橡樹與橡實的形態特徵，再轉成原創 SVG 元件。這裡的重點不是照抄照片，而是把可辨識特徵抽象化。

觀察重點

  • 橡實：橢圓堅果、杯狀 cupule、短柄。
  • 小苗：從橡實或根部附近萌發，早期有子葉。
  • 葉形：橡樹真葉具有裂片狀輪廓。
  • 花：雄花序下垂，雌花較小並發育成橡實。

轉譯方式

  • 用 path 做裂片狀葉，不用單純橢圓。
  • 用一串 circle 與曲線 path 呈現 catkins。
  • 用 body、cap、stem 三層組成橡實。
  • 用 CSS 變數控制不同生命階段顯示。
Pixabay 橡實照片觀察橡實本體、杯狀帽與枝條關係。 Pexels 橡實照片觀察未成熟橡實與樹上位置。 Wikipedia Acorn確認 acorn、cupule 等基本形態詞彙。 International Oak Society參考橡實大小、形狀與 cupule 差異。

SVG 生成策略

目前採用雙軌策略：Python 產生獨立 SVG 檔案，JavaScript 則在頁面中動態建立同款 SVG 結構。這讓資產可以單獨檢視，也讓實際頁面能跟番茄鐘狀態同步。

python .\tools\generate_oak_acorn_svg.py

Python 函式

tag()、oak_leaf()、catkin()、acorn() 負責把植物部件組成 SVG。

輸出檔案

assets/oak-acorn.svg 是生成結果，可直接用瀏覽器開啟，也用在本文件頁的 hero 視覺。

JavaScript 動畫流程

頁面載入後先建立 SVG，再載入 localStorage 狀態，最後 render。番茄鐘進度會被轉成五個 CSS 變數。

buildOakSvg();
hydrate();
render();
--seedling
--leafing
--growth
--flower
--fruit

這五個變數會控制小苗、葉、樹體、花與橡實的透明度、縮放與線條顯示。這個設計的好處是，JavaScript 只處理狀態與進度，視覺轉場交給 CSS。

驗證流程

python .\tools\generate_oak_acorn_svg.py
python -m py_compile .\tools\generate_oak_acorn_svg.py
node --check .\script.js
python -m http.server 8020 --bind 127.0.0.1

瀏覽器檢查項目

  • svg.oak-svg 是否存在。
  • .svg-seedling 是否存在。
  • .svg-young-leaf 是否有 2 個。
  • .svg-catkin 是否有 3 組。
  • .svg-female-flower 是否存在。
  • .svg-acorn 是否有 3 顆。
  • 按下「種下專注橡樹」後，倒數是否前進。
